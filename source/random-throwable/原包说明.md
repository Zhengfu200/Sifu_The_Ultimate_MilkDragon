# 《师父》V 键随机投掷物

空手时按 **V**，主角会拿起一件随机投掷物，随后自动执行一次轻攻击，将物品投出。当前物品池为砖块、硬盘、艺术摆件和玩偶。手里已有物品时，V 会保留当前物品。

自动攻击使用默认鼠标左键绑定。拾取后等待约 0.12 秒，发送一次鼠标左键按下，保持约 0.06 秒后松开。切换角色、打开菜单或丢失该物品时会取消本次自动攻击。

## 安装

适用版本为 Epic Windows `v_1.29_6.770`，需要已安装支持 EngineTick 的 UE4SS。本机使用 UE4SS 4.0.0 Experimental `b2d936b9`。

1. 退出游戏。
2. 将压缩包中 `Win64` 文件夹里的内容合并到游戏的 `Sifu\Binaries\Win64`，覆盖同名文件。包内脚本和 `ThrowableInputBridge.dll` 都需要复制。
3. 重启游戏，在主角可操作时按 **V**。

卸载时，退出游戏后移除 `Sifu\Binaries\Win64\ue4ss\Mods\SifuThrowStun` 文件夹。

输入桥接源码位于 `source/throw-stun/InputBridge.c`，使用 MinGW GCC 编译。
