# 《师父》T 键时停

适用版本为 Windows Epic《师父》`v_1.29_6.770`。本 Mod 使用随 ZIP 提供的 UE4SS `v4.0.0-9-gb2d936b9` 和为此游戏版本配置的 `VTableLayout.ini`。

## 使用

在可操作的场景中按 **T** 开启，再按 **T** 恢复。开启时使用原版 Focus 的黑白后处理，世界时间倍率为 0.10。主角的动作逻辑和骨骼动画以 1.50 倍为目标，退出时恢复开启前的倍率。受世界时间控制的场景物体也会减速。原版专注依旧通过 **F** 使用。

## 安装

1. 退出《师父》。
2. 将 ZIP 内 `Win64` 的内容复制到游戏的 `Sifu\Binaries\Win64`，与 `Sifu-Win64-Shipping.exe` 放在同一目录。若已有 UE4SS，先备份现有加载器和它的配置。
3. 从平常的游戏入口启动。可在「竞技场 → 训练 → 免费训练」测试。加载记录位于 `ue4ss\UE4SS.log`。

## 卸载

退出游戏，移出 `ue4ss\Mods\SifuTimeStop`。若 UE4SS 是仅为本 Mod 安装的，也可移出本包安装的 `dwmapi.dll` 和 `ue4ss` 文件夹。

ZIP 内的 UE4SS 来自[官方实验版发行页](https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/experimental-latest)，随附 MIT 许可。
