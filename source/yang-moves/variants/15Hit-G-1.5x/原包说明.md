# G 键十五拳连击

适用本机 Epic《师父》v_1.29_6.770，使用现有 UE4SS。

- 空手时按一次 G，自动连续发动三轮五段拳击，共十五拳。
- 普通与大师难度的全部命中配置均关闭格挡、招架、闪避和上下左右避让判定。攻击仍需接触目标。
- 攻击速度为原来的 1.5 倍。出招期间同步加快角色动作逻辑和骨骼动画，结束或中断时恢复先前的速度。
- 使用独立攻击配置和命中数据表，沿用每拳原有的伤害、架势伤害与动画。
- Z 为推踢，X 为冲刺扫腿，C 为三连击。
- 暂停、过场、倒地、死亡或持械时不发动。

退出游戏后，将 Paks/~mods 内的 pak 与 sig 复制到游戏 Sifu/Content/Paks/~mods。
将 Win64 内的 ue4ss/Mods/SifuYangMoves 复制到游戏 Sifu/Binaries/Win64/ue4ss/Mods。
已有本机测试版已直接更新。首次安装需要本机现有 UE4SS 和 YangInputBridge.dll。

卸载时退出游戏，移出 pakchunk98-YangMoves_P.pak、同名 sig 及 SifuYangMoves 模组目录。

源码在 source/yang-moves。重建命令为

```powershell
& './tools/dotnet/dotnet.exe' run --project source/yang-moves/ComboPatch -c Release -- 'build/yang-moves/inspect/Sifu/Content/DB/_MainChar/Combos/MainChar_ComboTree.uasset' 'build/yang-moves/stage' 'build/yang-moves/inspect'
& './tools/repak/repak.exe' pack 'build/yang-moves/stage' 'build/yang-moves/package/Paks/~mods/pakchunk98-YangMoves_P.pak' --mount-point '../../../Sifu/Content/' --version V11 --compression Zlib
```

核对记录为 build/yang-moves/15-hit-readback。已读回全部 8 个普通/大师命中行，确认 defense=0、avoidable=0、parriable=false、playAvoidedOrder=false、hitAnyCharacterOnAvoid=true。
