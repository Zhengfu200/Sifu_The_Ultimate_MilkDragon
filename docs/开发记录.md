# 《Sifu》奶龙 Mod

目标版本为 Epic Windows `v_1.29_6.770`，游戏目录为 `D:\Sifu`。新网格使用独立资产路径，男主默认服装通过 `BP_FightingPlayer` 指向它。游戏原来的网格也被部分其他服装和分身敌人使用。

## 本机安装与验证

### 墨绿竹笠游侠

- 男主默认套装显示 v14 奶龙，「都市穿搭」（Urban flair，索引 15）显示斗笠披风版。衣柜名称和图标沿用原栏位。
- 套装以浅色编织斗笠、墨绿到腰短披风和暖金扣组成。斗笠随头骨，披风使用脊柱蒙皮。离线检查了 91 帧原版动作和参考姿势，快速跑步、倒地闪避等少数样本仍有局部交叠。
- 工程、FBX、预览和离线检查在 `build/wanderer`。套装独立建模，斗笠纹理细节改自 [Grab3D Straw Hat](https://grab3d.com/models/props/straw-hat/)（[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)）。检索时参考了 [MushyDay 的 Asian Conical Hat](https://sketchfab.com/3d-models/asian-conical-hat-4eed68df8fb84284a91f42a6c6e4569c) 与 [POTVORA 的披风](https://sketchfab.com/3d-models/cloak-cape-free-a3418c3eedd449acbeea4fbe26118417) 的许可页面。这两个源文件的下载需要 Sketchfab 登录。
- 本机 Epic v_1.29_6.770 已安装。已在竞技场的「自定义模式 → 服装」中双向切换，重启后服装栏仍保留所选项。自由训练已验证加载、向前闪避和空手轻击。武馆衣柜及实机长棍握持待复核，包体读回已核对四个武器挂点，长棍防守也纳入离线姿势检查。截图位于 `build/wanderer/ingame`。
- 本机安装包为 `build/Nailoong-Sifu-Epic-6770-Wanderer-local.zip`。退出游戏后，将 `build/backups/before-wanderer-v14/local-mod` 中的同名 `.pak` 和 `.sig` 复制到 `~mods` 即可回退 v14。

在项目根目录重建套装与本机包：

```powershell
& 'tools/blender-5.2.1-windows-x64/blender.exe' -b --python-exit-code 1 --python scripts/build_wanderer.py -- --hat build/wanderer/source/grab3d-straw-hat-full.glb
& 'tools/blender-5.2.1-windows-x64/blender.exe' -b --python-exit-code 1 --python scripts/audit_wanderer.py
& 'scripts/Build-Mod.ps1' -UERoot 'D:/UE_4.26' -GripSockets 'build/grip-fix/sockets.json' -WandererOutfitIndex 15 -BaseNailoongPak 'build/local-mod/pakchunk99-Nailoong_P.pak'
```

## 构建本机测试版

在 PowerShell 7 中运行以下命令，使用本机已安装的 Unreal Engine 4.26.2。

```powershell
& 'D:\Project\Sifu\scripts\Build-Mod.ps1' -UERoot 'D:\UE_4.26' -GripSockets 'D:\Project\Sifu\build\grip-fix\sockets.json'
```

脚本读取 FBX 和贴图，导入并烘焙 UE 资产，修改 Epic 版男主的默认服装引用，并把输出放在 `build/local-mod`。UE 的导入和烘焙日志位于 `build`。重新安装时，退出游戏并把生成的 `.pak` 和同名 `.sig` 复制到 `~mods`。

## 公开发布

模型来源为 [WeDai 的奶龙建模仓库](https://github.com/bigdiu/naiwa-nailoong-blender-model)。确认修改版模型的公开分发授权和发布平台要求后，再生成公开包。成品仍需实测战斗、武器握持、过场和变老后的外观。
